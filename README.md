# guitara task

 a Flutter app that displays a list of products with details. The app  fetch data from a mock API like JSONPlaceholder or Fake Store API. The product list screen shows product names, images, and prices. Clicking on a product navigates to a details screen that displays the product’s name, image, description, and price. a clean Material Design for the interface with smooth transitions. state management using Provider  and offline support with SQLite to store product data locally.
