# guitara task

 a Flutter app that displays a list of products with details. The app should fetch data from a mock API like JSONPlaceholder or Fake Store API. The product list screen will show product names, images, and prices. Clicking on a product navigates to a details screen that displays the product’s name, image, description, and price. Use a clean Material Design for the interface with smooth transitions. Implement state management using Provider or Bloc and add offline support with SQLite to store product data locally.
